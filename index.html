🫖 教室の基本ノート

基本の考え方

基本の味は「焙じハトムギ」と「焙じハブ」。好みの野草を加えて、合計100gを目安にブレンド。

健康茶風の例

焙じハトムギ30g / 焙じハブ30g / クコ葉10g / クマザサ10g / カキ葉10g / ドクダミ10g

健胃風の茶の例

焙じハトムギ30g / 焙じハブ30g / クマザサ20g / チンピ20g

淹れ方

教室資料：1.8Lの水に10〜20gを入れ、10〜20分煮出す。夏は冷やしても可。

教室資料の内容を家庭用メモとして整理しています。伝統的な利用法の記録であり、病気の診断・治療・予防を目的とするものではありません。服薬中・妊娠中・持病がある場合などは医師・薬剤師へ確認してください。
